# Aurelia

This repository contains **AURELIA Connect**, a separate static integrations portal for the existing [AURELIA Lovable app](https://aurelia-coding-assistant.lovable.app).

The portal is in [`services/connect-portal/`](services/connect-portal/). It provides a copyable MCP client configuration, explains the OAuth connection flow, and links to the Lovable-hosted MCP and research-agent service. It is not a second copy of the Lovable application and does not store credentials or proxy protected MCP requests.

See the [service README](services/connect-portal/README.md) for run and deployment instructions.
